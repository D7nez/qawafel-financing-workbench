    Scope & assumptions

      Model card

      Metric definitions

      Net sales: valid unique invoice net amounts. Collection ratio: matched bank receipts ÷ gross accepted invoice value. Overdue: unpaid gross balance with due date before cutoff. Quarter change: last three months ÷ first three months − 1, not year-on-year growth. Receipts lag sales and include VAT; chart series have different accounting bases.

      Implemented

      XLSX / CSV validation, one text-PDF adapter, exact-reference matching, partial receipts, balance continuity, anomaly review, SQLite persistence and JSON export.

      Production roadmap

      Authentication, tenant isolation, malware scanning, encrypted object storage, asynchronous processing, OCR and bank-specific adapters, reviewer sign-off and a real bank integration. No real bank request is made by this prototype. Exact invoice references are the largest matching simplification: real statements often need amount/date/customer candidate matching and human confirmation.

      35% concentration and 10% overdue thresholds are illustrative review triggers, not bank policy. Invalid rows are quarantined; partial metrics never remove a blocker.
      SIMULATION ONLY

      Can repeated polls prove the bank is right?

      A bank API is wrong 3% of the time. Errors may be correlated; repeated responses cannot establish truth.

      Choose a scenario. No request will be sent to a bank. Simulation compares independent vs perfectly correlated 3% errors, conditioned on a known PENDING state; it is not a posterior probability.
      Keep internal status UNVERIFIED and obtain authoritative confirmation before a customer-facing terminal action. See the written submission for rollout, reconciliation and bank-call details.
      MOCK SOURCE APIs · LOCAL ONLY

      From source to evidence, automatically.

      Read fictional accounting and bank APIs over HTTP. No uploads, real bank login or API credentials.

      1. Grant scoped demo consent

      Scope: fictional-cedar-001 · Oct 2025-Sep 2026 · invoices and bank statement, read only. Consent lasts 60 minutes. This is a local simulation, not an OAuth or real bank consent process.

      2. Pull now or schedule

      Checks both manifests, verifies entity/period and file hashes, then runs the same validation and analysis pipeline. Unchanged hashes skip downloads. Data blockers require human correction; no financing request is sent.

      The server must remain running. Use one application worker. Expiry/revocation stops new reads and publication; already downloaded processing may finish in the local analysis cache. Revoking consent does not delete historical results.

      3. Simulate source changes & failures

      These controls change only the fictional source APIs. Apply a scenario, then wait for the next scheduled sync or select Sync sources now.

      Synchronization run history

      Persisted locally. Only successful verified imports advance the content checkpoint; a package with data blockers is recorded as Needs review. Failed pulls retain the previous package.
